# LiteSplice — downloads

This repository holds **the installers only**. The source lives in a private repo.

- **Windows:** download the `.exe` from the latest release on the right, run it, and click past the
  "Windows protected your PC" warning (More info → Run anyway) — the app is not code-signed yet.
- **Updates:** LiteSplice checks for a new version when it starts. When one is out, the main menu shows
  a card saying so, with **Download update**, **Not now** and **What's changed**. Nothing downloads until
  you press Download, and it never restarts you on its own — you choose **Restart now** when it is ready.

The first download is large (about a gigabyte): the AI models for the Smart Brush, Refine Edge, smooth slow
motion and stem separation are included, so everything works offline with nothing else to install.
